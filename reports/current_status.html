04 Open Issues
ISSUE-001
CRITICAL RESOLVED
complex_mult_iq: s_axis_tready hardwired 1'b1, ignores m_axis_tready
Root cause: lines 44–45 in complex_mult_iq.v. s_axis_a_tready was tied high, ignoring downstream backpressure, causing data loss and SSS deadlock in the integration path.

Fix applied 2026-06-02: can_accept = !m_axis_tvalid || m_axis_tready; output register gated on can_accept. NCO enable in frac_cfo_corrector_top.v gated on s_axis_iq_tready to prevent phase drift during AXI-S stalls.
Resolved 2026-06-02 P3-16A PASS (8/8) P3-20A PASS (37/37) P3-23A PASS (23/23)
ISSUE-002
MEDIUM RESOLVED
session_D4: random equivalence failures — RESOLVED 2026-06-03
Root Cause: Verilog race condition in tb/session_D3_p3_15c_equiv_tb.sv AXI-S stimulus loop. Testbench @(posedge aclk) + blocking assign to s_axis_tdata fired at the same simulation time as DUT always @(posedge aclk), causing non-deterministic sample skip/duplicate in iq_frame_buffer. Fix: added #1 after each @(posedge aclk) in the stimulus loop.

Verification: RANDOM_EQUIV_GATE 100/100 PASS after fix (was 99/100).
