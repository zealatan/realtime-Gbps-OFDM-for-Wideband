OFDM Receiver Synchronizer — signal-flow block diagram

Top module phase3_sync_axis_dma_wrapper: AXI-Lite control/status slave + AXI-Stream slave (raw IQ from DMA/player) + AXI-Stream master (frac+integer corrected IQ to DMA). The DUT estimates and removes fractional CFO + timing (live stream), estimates the integer CFO via an FFT-correlation Meyr core (off the corrected stream), and applies the integer correction with a CORDIC NCO + complex rotator on the way out.
