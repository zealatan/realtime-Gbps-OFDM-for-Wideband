# Session F / P3-17A: Board / Vitis Smoke Revalidation

## Gate

```
SMOKE_GATE: PASS when all 14 checks pass on hardware.
            BLOCKED until bitstream generated from Phase3 RTL.
```

---

## Objective

Revalidate the board/Vitis integration path using the existing **Phase2 Vivado
shell** with the Phase3 bitstream loaded.  The smoke test drives the golden IQ
stimulus over AXI DMA, monitors the Phase3 AXI-Lite register bank, and verifies
that the full pipeline — frame detection, fractional CFO correction, Meyr integer
CFO estimation, and replay-buffer integer CFO correction — produces the expected
observable outputs on real hardware.

## Hardware Prerequisites

### 1. Base Addresses

Open the Vivado **Address Editor** (`Window → Address Editor`) and update the
two `#define` lines near the top of `vitis/session_F_p3_17a_phase3_smoke.c`:

```c
#define SYNC_BASEADDR   0x43C00000U   /* phase3_sync_axis_dma_wrapper AXI-Lite */
#define DMA_BASEADDR    0x40400000U   /* Xilinx AXI DMA                         */
```

Typical Zynq-7000 (AXI GP0) mappings are shown above; confirm against your
block design.

### 2. XSA Export

In Vivado: **File → Export → Export Hardware** (include bitstream).  Point
`XSA_PATH` in the .bat script to the resulting `.xsa` file.

### 3. Processor Target

The .bat script defaults to `standalone_ps7_cortexa9_0` (Zynq-7000).
For Zynq UltraScale+ change to `standalone_psu_cortexa53_0`.

### 4. DMA Device ID

If the AXI DMA is not the first DMA in the design, change the `0` in:

```c
dma_cfg = XAxiDma_LookupConfig(0);
```

to the correct device ID from `xparameters.h` (search for `XPAR_AXIDMA_*_DEVICE_ID`).

## IQ Stimulus

The embedded `iq_stim[]` array is the golden deterministic stimulus from
`golden/phase3_iq_stimulus.mem` (generated by `scripts/gen_phase3_iq_stimulus.py`).

- Total: 704 samples × 32 bits = 2816 bytes
- Structure: `[zeros×64][CP1+S1=288][CP2+S2=288][zeros×64]`
- Format per word: `bits[31:16]=Q, bits[15:0]=I` (signed 16-bit each)
- Expected frame detection at sample ~41, slot start at sample ~64
- Non-zero range: indices 64–639

---

## Register Map Reference

All registers are 32-bit, AXI-Lite byte-addressed from `SYNC_BASEADDR`.

| Offset | Name | Access | Notes |
|--------|------|--------|-------|
| 0x00 | VERSION | R | Constant 0x00316001 |
| 0x04 | CONTROL | R/W | bit0=enable, bit1=soft_reset(W1S) |
| 0x08 | STATUS | R/W1C | bit0=busy, bit1=done_seen, bit2=error_seen |
| 0x0C | FRAME_LEN_SAMPLES | R/W | [11:0] default 576 |
| 0x10 | INPUT_COUNT | R | S_AXIS accepted beats |
| 0x14 | OUTPUT_COUNT | R | M_AXIS accepted beats |
| 0x18 | FRAME_START_VALID | R/clr | Sticky; read clears |
| 0x1C | FRAME_START_INDEX | R | Latched on FRAME_START_VALID |
| 0x20 | PEAK_INDEX | R | Latched on FRAME_START_VALID |
| 0x24 | SLOT_START_INDEX | R | Latched on SLOT_START_VALID |
| 0x28 | FRAC_CFO_VALID | R/clr | Sticky; read clears |
| 0x2C | FRAC_CFO_PHASE | R | Q1.15 sign-extended 16→32 |
| 0x30 | PSS_DONE | R/clr | Sticky (not yet wired) |
| 0x34 | SSS_DONE | R/clr | Sticky (not yet wired) |
| 0x38 | INT_CFO_VALID | R/clr | Sticky; read clears; **triggers snapshot** |
| 0x3C | INT_CFO_EST | R | 32-bit NCO step word (snapshot) |
| 0x40 | INT_CFO_INDEX | R | Meyr peak index (snapshot) |
| 0x44 | INT_CFO_APPLIED | R | 1 after replay + rotation complete |
| 0x48 | RESET_STATUS | R/W1C | bit0=RESET_DONE, bit1=PIPELINE_IDLE |
| 0x4C | DEBUG_CONTROL | R/W | bit0=bypass, bit2=counter_clear |
| 0x50 | TLAST_COUNT | R | Output TLAST count |
| 0x54 | ERROR_FLAGS | R/W1C | [3:0] FRAME_LEN_MISMATCH/TLAST_TIMEOUT/RESET_WHILE_ACTIVE/STALL_TIMEOUT |

---

## Snapshot Protocol

When SW reads `INT_CFO_VALID` (0x38) while the latch holds 1, all sync result
registers (FRAME_START_INDEX, PEAK_INDEX, SLOT_START_INDEX, FRAC_CFO_PHASE,
INT_CFO_EST) are frozen simultaneously into shadow registers.  This guarantees
consistent reads even if the next frame arrives immediately after.

The smoke test polls this register after DMA completion and reads the snapshot
fields if the latch fires within 500 ms.
