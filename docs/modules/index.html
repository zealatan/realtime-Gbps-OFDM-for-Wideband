S5 Key Design Parameters

Parameter Value Description Units / Derivation
FRAME_LEN 576 Total frame capture buffer depth = 2 × (NSC + CP_LEN) = 2 × 288
NSC 256 Number of subcarriers / FFT point count samples
CP_LEN 32 Cyclic prefix length per OFDM symbol samples
FFT_SIZE 256 FFT size (same as NSC) = NSC; used for fft256_xilinx_wrapper
PSS_OFFSET 32 PSS window start within corrected frame = CP_LEN; sample index 32–287
SSS_OFFSET 320 SSS window start within corrected frame = 2 × CP_LEN + NSC = 64 + 256; samples 320–575
IQ_WIDTH 16 Bit width per IQ component (I and Q each) bits; signed two’s complement
NCO_PHASE_WIDTH 32 NCO phase accumulator width bits; wraps at 2³²
CORDIC_LATENCY 15 CORDIC pipeline stages; total latency = 16 clocks 15 iteration regs + 1 output register
FLUSH_COUNT 1 FFT frames flushed per symbol to clear pipeline frames
LAG_COUNT 511 Number of correlation lags in Meyr estimator = 2 × NSC − 1 = 511
CENTER 255 Zero-CFO peak index in lag array = NSC − 1 = 255; k_int = peak_index − CENTER
THRESHOLD 10240000 Default frame detection energy threshold = 40000 × 256 (Q1.15 scaled); 40000 used for amp=3000 (XIP-004)
NCO_WU_CYCLES 16 Integer NCO warm-up cycles before valid output = CORDIC_LATENCY + 1 = 16
