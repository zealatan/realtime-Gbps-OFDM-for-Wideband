This module is the innermost algorithm engine. It accepts raw IQ from phase3_sync_top, internally manages a frame capture buffer, runs frame detection and CP timing, estimates the fractional CFO via CORDIC atan2, then streams TOTAL_SAMPLES of frac-corrected IQ on m_axis. The single aresetn and start interface from the parent FSM are the only control inputs.

Clock Domain and Reset

Single clock domain: aclk. Reset aresetn is the wrapper's dut_aresetn (hard + soft reset combined). The FSM uses synchronous reset: if (!aresetn) inside a posedge-always block. All sub-modules share the same aresetn.

The ACQ_WATCHDOG_CYCLES parameter (default 0 = disabled) enables an inactivity watchdog during S_FILL. When non-zero, if ACQ_WATCHDOG_CYCLES consecutive clock cycles pass without an accepted IQ sample in S_FILL, the module asserts frame_error with error_code=6 (INPUT_ACQ_TIMEOUT) and exits to S_DONE.

7 Operation

S_IDLE — Waiting for Start

FSM waits with busy=0. On start && !busy: set busy=1, clear error_code_r=0, pulse buf_capture_start=1 (starts iq_frame_buffer capture mode), transition to S_FILL.

S_FILL — AXI-S Buffer Capture

The iq_frame_buffer accepts incoming IQ samples via its s_axis interface. s_axis_tready is asserted by u_buf while the buffer has space. The buffer captures exactly 2^BUF_AW = 4096 samples (or until buf_capture_done asserts). During S_FILL, the ACQ watchdog is active if ACQ_WATCHDOG_CYCLES > 0: if the watchdog counter reaches ACQ_WATCHDOG_CYCLES-1 without an accepted sample, acq_timeout_w fires, frame_error=1, error_code_r=6, and the FSM jumps to S_DONE.

On buf_capture_done: pulse fd_start_r=1, transition to S_FRAME_DET.

S_FRAME_DET — Frame Detection

The buf_rd_addr/buf_rd_en mux connects to fd_buf_rd_addr/fd_buf_rd_en (frame_detector drives these). The frame_detector performs a sliding-window energy scan over the buffer looking for a sustained period where IQ power falls below the threshold (indicating a CP correlation peak). When fd_done asserts:

  • If fd_frame_found=1: latch frame_index_r = fd_frame_index, pulse tfc_start_r=1, transition to S_TIMING_CFO.
  • If fd_frame_found=0: set frame_error=1, transition to S_DONE (no error_code set = code 0).

S_TIMING_CFO — CP Autocorrelation and CORDIC atan2

buf_rd_addr/en mux connects to tfc_buf_rd_addr/tfc_buf_rd_en (frame_frac_cfo_top). The u_tfc module reads CP-length windows from the buffer at base_addr = frame_index_r, computes the VanDeBeek autocorrelation for each lag (0..NSC-1), finds the peak, then applies CORDIC atan2 to get the fractional CFO phase.

When tfc_done asserts: latch peak_lag_r = peak_lag, frac_phase_r = frac_phase, compute slot_start_r = frame_index_r + peak_lag, reset nco_cnt=0, transition to S_LOAD_NCO.

S_LOAD_NCO — NCO Load, Reset, and Warmup

The NCO sequencing uses a 5-bit counter nco_cnt (0..NCO_WAIT) with combinatorial decode:

  • nco_cnt=0: nco_load_step_w=1 → step_word loaded into u_corr NCO phase accumulator.
  • nco_cnt=1: nco_phase_reset_w=1 → NCO phase accumulator cleared to 0.
  • nco_cnt=2..NCO_WAIT-1: nco_enable_w=1 → NCO CORDIC pipeline runs; sin/cos values flow through the 15-stage CORDIC pipeline.
  • nco_cnt=NCO_WAIT=17: sincos_valid should be asserted (pipeline fully primed); latch initial play_rd_ptr=0, play_rd_pend=0, play_hold_valid=0; transition to S_CORRECT.

The step_word is computed as: step_word_w = {{8{frac_phase_r[15]}}, frac_phase_r, 8'h00} — this is sign-extend-8 of frac_phase_r concatenated with 8 zero bits. Equivalently: step_word_w=+frac_phase_r·28 (as a 32-bit signed fixed-point number). The positive sign means the NCO rotates at +frac_phase frequency to cancel the negative frac CFO in the input signal.

S_CORRECT — Corrected IQ Stream Playback

The buffer read mux is: buf_rd_addr = slot_start_r + play_rd_ptr. The play sequencer uses a 2-cycle pipeline (1 cycle BRAM read latency + 1 hold register stage) to match the sample rate to the corrector acceptance rate:

  1. can_issue: asserts when no pending read is outstanding (!play_rd_pend), there are remaining samples (play_rd_ptr < TOTAL_SAMPLES), and the hold register is either empty or being consumed (!play_hold_valid || corr_accept).
  2. When can_issue=1: issue buffer read (buf_rd_en=1), set play_rd_pend=1, advance play_rd_ptr.
  3. On the next cycle (play_rd_pend=1): capture buf_rd_data into play_hold_data, set play_hold_valid=1, clear play_rd_pend.
  4. corr_accept = play_hold_valid && corr_tready: when the corrector accepts a sample, clear play_hold_valid.
  5. When play_hold_last && corr_accept: last sample consumed; transition to S_DONE.

This 2-cycle pipeline (BRAM read + hold register) limits throughput to 1 sample per 2 clocks maximum. The corrector (frac_cfo_corrector_top with CORDIC pipeline) processes each sample with NCO enable=1 continuously during S_CORRECT.

S_DONE — Completion

done=1 (registered, 1 cycle), busy=0, transition to S_IDLE. Frame_error and error_code_r remain latched until cleared at the start of the next run.

NCO Step Word Direction

The step word +frac_phase·28 (A-FIX2 convention) is chosen so that the corrector rotates at the same frequency as the CFO (not opposite). This is correct because: frac_phase = CORDIC atan2 output = angle of the CP correlation complex sum = the carrier frequency offset accumulated over CP_LEN samples. The corrector must multiply by e +j2π·frac_phase·n/NSC to cancel the e −j(·) rotation introduced by the CFO in the received signal. Contrast with the integer CFO step word in phase3_sync_top which uses negation.

15 Known Issues / Lessons Learned

ISSUE-001 RESOLVED (P3-14C): complex_mult_iq.v backpressure bug. This module calls frac_cfo_corrector_top which contains complex_mult_iq. The bug caused corr_tready=0 even when m_axis_tready=1 (output was valid and downstream was ready, but module incorrectly held tready low). Fix: can_accept = !m_axis_tvalid || m_axis_tready. After fix: S_CORRECT runs smoothly at 0.5 smp/clk with no stalls when m_axis_tready=1.
ISSUE-002 RESOLVED (P3-15D statistical gate): TB AXI-S race fixed. The 100-frame statistical test caught intermittent first-sample errors caused by the TB driving s_axis_tvalid in the same delta as posedge aclk. Fix: #1 delay in TB.
S_CORRECT throughput is fundamentally limited to 0.5 smp/clk by the BRAM read pipeline. The play_rd_pend mechanism ensures only one read is outstanding at a time (BRAM has no read-ahead buffering). A future enhancement could add a 2-stage read pipeline to approach 1 smp/clk, but this requires careful handling of two simultaneous outstanding reads and two hold registers.
slot_start_r = frame_index_r + peak_lag: this is the starting buffer address for the corrected output playback. The buffer wraps modulo 2^BUF_AW (4096). If frame_index is near the end of the buffer (e.g., 4090) and peak_lag=8, slot_start wraps around. The iq_frame_buffer must handle this wrap-around in its read address generation.
ACQ_WATCHDOG_CYCLES=0 (default disabled): the watchdog is a new feature (Step 43). When enabled, it catches scenarios where the DMA stalls mid-frame and the module would otherwise wait indefinitely in S_FILL. For FPGA bring-up, consider enabling with a large value (e.g., 65535 cycles) to detect DMA stall conditions without false triggering during normal backpressure events.

Reset Sequence (numbered)

  1. Apply aresetn=0 for ≥8 cycles; ILA should show state=S_IDLE, busy=0, frame_error=0.
  2. Release aresetn=1; parent (phase3_sync_top) will deliver start pulse.
  3. Observe state transitions: S_IDLE→S_FILL on start pulse; s_axis_tready should assert.
  4. In S_FILL: monitor buf_capture_done; expect after ~576 input beats (or when buffer full at 4096).
  5. In S_FRAME_DET: monitor fd_done and fd_frame_found; if fd_frame_found=0 on valid input, check threshold_in value.
  6. On tfc_done: read frame_index_r, peak_lag_r, frac_phase_r from ILA; cross-check all three against C reference.
  7. In S_LOAD_NCO: verify nco_cnt increments 0→1→...→17; confirm frac_cfo_corrector_top sincos_valid asserts at nco_cnt=17.
  8. In S_CORRECT: monitor play_rd_ptr incrementing; confirm m_axis_tvalid pulses every 2 cycles approximately.
  9. Verify m_axis_tlast fires when play_rd_ptr=TOTAL_SAMPLES-1 (575 for 576-sample output).
  10. Verify done fires 1 cycle after last m_axis handshake; state returns to S_IDLE.

AXI-Lite Register Notes

This module does not have a direct AXI-Lite interface. Results are read via the wrapper's AXI-Lite register bank (phase3_axi_lite_regs) through debug output ports of phase3_sync_top. Key registers: 0x1C (frame_index), 0x20 (peak_lag), 0x2C (frac_phase).

Hardware Risks

  • Buffer address wrap: if slot_start_r + play_rd_ptr wraps past 2^BUF_AW, the iq_frame_buffer read address wraps. Verify that the buffer correctly handles this (modular arithmetic on the BRAM address).
  • CORDIC sign: if frac_phase_r has wrong sign, the corrected output will have 2x CFO instead of 0. Verify by injecting a known frac CFO and checking the corrected output phase is flat.
  • ACQ watchdog: when enabled (ACQ_WATCHDOG_CYCLES non-zero), ensure the DMA can deliver samples within the watchdog window. The watchdog counter is 16-bit; maximum watch period = 65535 cycles.

17 Debug Checklist

  1. Verify state=S_IDLE, busy=0, frame_error=0 after reset.
  2. Confirm buf_capture_start pulses exactly 1 cycle on start transition to S_FILL.
  3. Verify s_axis_tready=1 during S_FILL; deasserts in S_FRAME_DET and later states.
  4. Count s_axis accepted beats in S_FILL: confirm buf_capture_done after expected count.
  5. Verify fd_done fires with fd_frame_found=1 for valid input; check frame_index_r vs C reference.
  6. Verify tfc_done fires; check peak_lag_r and frac_phase_r vs C reference VanDeBeek + atan2 outputs.
  7. Confirm slot_start_r = frame_index_r + peak_lag_r (simple arithmetic check in ILA).
  8. Verify nco_cnt in S_LOAD_NCO counts 0→17 (17 steps exactly).
  9. In S_CORRECT: verify play_rd_ptr increments by 1 every 2 cycles (can_issue every other cycle).
  10. Test backpressure: hold m_axis_tready=0 for 20 cycles in S_CORRECT; verify play_rd_ptr freezes and no output beats lost when tready resumes.
  11. Verify m_axis_tlast fires at correct beat (TOTAL_SAMPLES-1).
  12. Check total m_axis valid beats = TOTAL_SAMPLES (576 or 288 depending on OUTPUT_SAMPLES).
  13. After done: verify frame_error=0 for successful run; busy=0.
  14. Test error path: inject empty (all-zero) input; verify frame_error=1, frame_found=0, error_code=0 (default error code when frame not found).

18 Review Notes

Non-Obvious Design Decisions

  • Shared buffer read port (mux design): The iq_frame_buffer has a single read port shared between frame_detector, frame_frac_cfo_top, and the correction playback sequencer. This is managed by the FSM-state-based combinatorial mux. The states are sequential (FRAME_DET → TIMING_CFO → CORRECT), so no arbitration is needed — only one module needs the read port at a time. This saves one BRAM read port and simplifies routing.
  • OUTPUT_SAMPLES=0 default: The parameter default of 0 means "use NSC+CP_LEN" is the correct interpretation. The ternary localparam TOTAL_SAMPLES = (OUTPUT_SAMPLES>0) ? OUTPUT_SAMPLES : (NSC+CP_LEN) handles this. A future engineer passing OUTPUT_SAMPLES=0 explicitly will get the default behavior, not a counter width of 1 bit.
  • nco_cnt sequencing: The NCO requires explicit load (nco_cnt=0), then reset (nco_cnt=1), then warm-up (nco_cnt=2..16), then ready (nco_cnt=17). The combinatorial decode wires nco_load_step_w, nco_phase_reset_w, nco_enable_w are purely combinatorial from nco_cnt and state. This avoids extra registered pulses that would require an additional FSM cycle.
  • Step word direction (+frac_phase·28): Positive, unlike the integer CFO step in phase3_sync_top (negative). This is because frac_phase = atan2 of the CP autocorrelation complex sum, which directly gives the positive phase rotation per symbol. The correction must add the same rotation per sample to cancel the CFO.
  • play_rd_pend as a state bit: The 1-bit play_rd_pend register serves as a state for the 2-cycle BRAM read pipeline. It prevents the sequencer from issuing a second read before the first result has been captured into play_hold. Without this, two back-to-back reads would overwrite the first result before it could be consumed.
  • can_issue condition includes !play_hold_valid || corr_accept: The "or corr_accept" term means a new read can be issued in the same cycle that the hold register is being consumed. This eliminates a dead cycle between consecutive corrections and improves throughput from 1/3 to 1/2 samples per clock.

Open Items for Future Engineers

  • Consider adding ACQ_WATCHDOG_CYCLES to AXI-Lite register space for runtime configurability during FPGA debug.
  • The 0.5 smp/clk output throughput could be improved to 1 smp/clk by adding a 2-entry read-ahead FIFO in the play sequencer. This requires handling simultaneous outstanding reads, which complicates the play_rd_pend logic but doubles corrected output rate.
  • The TIMING_PROBE ifdef block (lines 504–519 in RTL) is for simulation only; it is harmless in synthesis but should be removed in production RTL to keep the code clean.
  • Error code 6 (INPUT_ACQ_TIMEOUT) is only possible when ACQ_WATCHDOG_CYCLES > 0. The error_code output is always driven from error_code_r which is 0 by default. Consider documenting all possible error codes (0=none, 6=watchdog) more explicitly in the port comment.
