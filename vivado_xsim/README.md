# vivado_xsim — Vivado xsim Real Xilinx FFT IP Verification Flow

## Purpose

Provide a two-tier simulation strategy for the RTL_SYNC_PHASE4 FFT path:

| Tier | Tool | IP Model | Authority |
|------|------|----------|-----------|
| Fast pre-check | iverilog | `USE_BEHAVIORAL_STUB=3` | Development only — NOT final gate |
| **Authoritative gate** | **Vivado xsim** | **Real Xilinx xfft 9.1 VHDL** | **Required for PASS_VIVADO_XSIM_REAL_IP** |

Any path that involves Xilinx FFT IP must achieve `PASS_VIVADO_XSIM_REAL_IP` via this flow
before the gate is closed.  `PASS_BEHAVIORAL_ONLY` is an open item, not a closure.

## Gate Labels

| Label | Meaning |
|-------|---------|
| `PASS_VIVADO_XSIM_REAL_IP` | Gate closed — real Xilinx xfft 9.1 VHDL passed |
| `PASS_BEHAVIORAL_ONLY` | Behavioral stub passed; real IP gate still open |
| `FAIL_VALUE_MISMATCH` | Bin magnitudes outside tolerance |
| `FAIL_PROTOCOL` | AXI-S handshake or tlast error |
| `BLOCKED_XCI_NOT_FOUND` | XCI/VHDL sim model missing |
| `BLOCKED_WINDOWS_VIVADO_REQUIRED` | Generated for Windows reference only |

## FFT IP Key Facts

- xfft 9.1, 256-point, 16-bit fixed-point, natural_order output, scaled mode
- SCALE_SCH=0xAA → 4 of 8 pipeline stages divide by 2 → **total scale factor = 1/16 (0.0625)**
- Config word: `CFG_TDATA = 16'h0155` (FWD, scale applied)
- **No `aresetn` port** on the IP (C_HAS_ARESETN=0)
- **No `event_fft_overflow`** (ovflo=false)
- **Realtime throttle**: `m_axis_data_tready` NOT wired to IP — output streams freely
- `xk_index=true`: bin index in `m_axis_data_tuser[7:0]`
